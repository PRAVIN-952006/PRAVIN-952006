# Security policy

Workflow Guard is a defensive static-analysis tool. Please do not include secrets, private repository data, or unauthorised target information in reports.

## Reporting a vulnerability

Report vulnerabilities privately through the repository's GitHub security advisories if enabled. If private reporting is unavailable, open a minimal issue requesting a private contact channel without disclosing exploit details.

Reports should include the affected version, a reproducible local example, expected impact, and a suggested mitigation where possible.
